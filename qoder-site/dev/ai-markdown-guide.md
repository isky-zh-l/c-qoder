# AI 排版语法说明

本文件是 AI 润色功能使用的语法白名单。AI 只能使用下面列出的 Markdown 子集；
超出范围的 HTML、脚本、样式和远程图片一律不得输出。

## 一、块级语法

| 写法 | 效果 | 示例 |
| :--- | :--- | :--- |
| `# 一级标题` | 大标题 | `# 指针与内存` |
| `## 二级标题` | 中标题 | `## 一、地址与指针` |
| `### 三级标题` | 小标题 | `### 1.1 取地址` |
| 空行分隔 | 段落 | 连续文字之间空一行 |
| `> 文字` | 紫色引用框 | `> 提示：先理解地址再学指针。` |
| `---` | 分隔线 | 单独一行三个短横线 |
| `- 项目` / `* 项目` / `+ 项目` | 圆点列表 | `- 指针保存地址` |
| `1. 项目` | 编号列表 | `1. 声明指针` |
| `- [ ] 项目` / `- [x] 项目` | 待办列表 | `- [x] 已完成` |
| 管道表格 | 表格 | 见下方 |
| 三个反引号围栏 | 代码块 | 见下方 |
| `$$` 包裹 | 块级公式 | 见下方 |

### 表格

```text
| 名称 | 作用 |
| :--- | :--- |
| `malloc` | 申请堆内存 |
| `free` | 释放堆内存 |
```

单元格内可以使用行内代码、加粗和链接；单元格内不要出现未转义的竖线。

### 代码块

在三个反引号后写语言标记 `c`、`h` 或 `text`：

````text
```c
int main(void) {
    return 0;
}
```
````

代码内容必须原样保留，不做格式化，不添加注释，不改变缩进。

### 块级公式

使用 KaTeX 语法，单独成块：

```text
$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
```

公式内容必须原样保留。

## 二、行内语法

| 写法 | 效果 | 示例 |
| :--- | :--- | :--- |
| `**文字**` | 加粗 | `**重点**` |
| `*文字*` | 斜体 | `*强调*` |
| `<u>文字</u>` | 下划线 | `<u>必须记住</u>` |
| `~~文字~~` | 删除线 | `~~旧写法~~` |
| `` `代码` `` | 行内代码 | `` `sizeof` `` |
| `[标题](https://example.com)` | 链接 | `[C 标准](https://example.com)` |
| `$...$` | 行内公式 | `$O(n\log n)$` |
| `==文字==` | 默认黄色高亮 | `==结论==` |
| `<mark data-tone="yellow">文字</mark>` | 黄色高亮 | 关键词 |
| `<mark data-tone="purple">文字</mark>` | 淡紫高亮 | 对比项 |
| `<mark data-tone="mint">文字</mark>` | 薄荷绿高亮 | 正确写法 |
| `<mark data-tone="pink">文字</mark>` | 浅粉高亮 | 易错点 |

高亮 token 只允许 `yellow`、`purple`、`mint`、`pink` 四种。
旧数据里的 `green` 按 `mint` 显示，`blue` 按 `purple` 显示。

## 三、禁止内容

- 任意 HTML 标签，除 `<u>` 和 `<mark data-tone="...">`；
- `style` 属性、事件属性（`onclick` 等）、`<script>`、`<style>`、`<iframe>`、`<object>`、`<embed>`；
- `javascript:`、`vbscript:`、`data:`、`file:` 链接；
- 远程图片、图片外链、`<img>` 标签；
- 自动播放、脚本、表单和任何交互元素。

## 四、AI 排版要求

1. 只做结构与排版：补充小标题、拆分段落、归纳列表、整理表格、给关键词加高亮；
2. 不新增原文没有的技术结论，不删除原有内容，不改变 C 代码和公式；
3. 代码块、公式、链接和已有高亮原样保留；
4. 只输出处理后的 Markdown 全文，不输出解释、前言、结尾或代码围栏包裹的全文；
5. 必须使用上面的语法，不得自创语法。
